What happens when you run a review
  1. The diff is applied to a private copy of the repository, so base and head can be compared.
  2. Tree-sitter builds a call graph; every caller up to two hops from a changed function is found and checked against the new signature.
  3. Security, contract and regression reviewers run in parallel. The regression reviewer writes edge-case tests and runs them on both revisions in a sandbox.
  4. A critic drops findings that point at code the PR didn't change, merges duplicates, and filters unverified low-confidence items.
