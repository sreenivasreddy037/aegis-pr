# AGENTS.md — working on AegisPR

Guidance for humans and coding agents contributing to this repository.

## Directory map

| Path | Purpose |
|---|---|
| `app/config.py` | Pydantic `BaseSettings`; the only place env vars are read |
| `app/schemas.py` | Pydantic v2 domain models (`DiffHunk`, `ImpactNode`, `ReviewFinding`, `PRReviewReport`, ...) |
| `app/ast_engine/parser.py` | Tree-sitter Python symbol / call-site / import extractor |
| `app/ast_engine/impact_graph.py` | NetworkX call graph, 2-hop upstream resolution, signature & call-site contract checks |
| `app/ast_engine/diff_utils.py` | Unified diff parser and strict, context-verified patch applier |
| `app/analysis/security_rules.py` | AST-aware security rules (CWE-89/78/95/798/532/502/369) on added lines |
| `app/analysis/edge_cases.py` | Edge-case pytest synthesis for modified functions (differential base vs head) |
| `app/retrieval/policy_store.py` | Qdrant hybrid (dense + sparse, RRF) retrieval over ADRs & security policies |
| `app/sandbox/test_runner.py` | Isolated subprocess pytest runner (timeouts, rlimits, scrubbed env, no network) |
| `app/graph/review_graph.py` | LangGraph `StateGraph`: `analyze_impact` → `Send` fan-out → `critic_synthesizer` |
| `app/graph/agents.py` | Node implementations for the three reviewers and the critic |
| `app/graph/llm.py`, `prompts.py` | Live OpenAI structured-output LLM + deterministic `MockReviewLLM` |
| `app/api.py`, `app/cli.py` | FastAPI service and Typer/Rich CLI |
| `app/web/` | Browser UI (`index.html` + `static/app.css`, `static/app.js`), served by FastAPI at `/`; no build step |
| `app/evaluation.py` | Benchmark scoring (recall / precision / latency percentiles) |
| `fixtures/sample_repo/` | Multi-file payments microservice + `sample_pr.diff` with 3 seeded bugs |
| `evals/` | `benchmark_prs.json` (12 PRs, generated by `build_benchmark.py`) and the eval suite |
| `tests/` | Unit + integration tests (AST, sandbox, retrieval, pipeline, API, CLI, web UI) |
| `scripts/build_pages.sh` | Builds the static GitHub Pages preview (UI + a demo report generated by the real pipeline) into `site/` |
| `.github/workflows/` | `ci.yml` (lint, tests, demo, container smoke test) and `pages.yml` (deploys the preview) |
| `docs/` | README screenshots: CLI `--svg` exports and web UI captures |

## Commands

```bash
uv sync                                   # install (Python 3.12)
uv run ruff check . && uv run ruff format .
MOCK_LLM=true uv run pytest -v            # full suite incl. benchmark evals, offline
MOCK_LLM=true uv run aegispr review --demo
uv run aegispr review --repo PATH --diff change.diff [--json] [--fail-on high]
uv run aegispr benchmark                  # ABLATION=no_impact_graph|no_sandbox for ablations
uv run aegispr serve                      # web UI + API on http://localhost:8000
uv run python evals/build_benchmark.py    # regenerate sample_pr.diff + benchmark_prs.json
docker compose up --build
```

## Code style

- `ruff` (lint + format), line length 100, target `py312`. CI fails on any lint error.
- Type hints everywhere; Pydantic v2 models at module boundaries; no `os.environ` reads outside `app/config.py`.
- `fixtures/sample_repo/` is intentionally buggy code and is excluded from ruff. Edit it only together with
  `evals/build_benchmark.py`, then regenerate the benchmark.

## Architectural invariants (do not break)

1. **Deterministic structure before LLM calls.** The AST impact graph, contract checks, security rules and
   sandbox runs execute before any LLM is consulted; LLMs adjudicate and explain candidates, they never review
   a bare diff. An LLM may reword but never discard a `verified=True` finding.
2. **Sandboxed execution only.** Generated tests run exclusively through `app/sandbox/test_runner.run_pytest`
   on a throwaway copy, with a strict timeout (`SANDBOX_TIMEOUT_SEC`, process-group kill), rlimits, a scrubbed
   environment and network disabled. Never `exec`/`import` generated code in the server process.
3. **Grounded output.** The critic drops any finding whose file/line is not in the diff (security/regression)
   or not a known call site (breaking change). Keep that check when adding new categories.
4. **Untrusted text stays text.** Report content comes from analysed code. The web UI inserts it with
   `textContent` only (a test forbids `innerHTML`-style sinks in `app/web/static/app.js`).
5. **No hardcoded secrets.** Keys come from the environment / `.env` (git-ignored). `.env.example` documents them.
6. **Offline CI.** `MOCK_LLM=true` (or no `OPENAI_API_KEY`) must make the whole pipeline, tests and demo run
   with no network access. New LLM features need a deterministic mock path.
7. **Parallel agents stay independent.** Reviewer nodes communicate only through reducer-merged state
   (`findings`, `sandbox_runs`, `timings_ms`, `errors`); an agent crash is reported, not fatal.
